# Bliss Shaders (Fork)

A fork for continued development and purposeful patches to the [Bliss shader pack](https://github.com/X0nk/Bliss-Shader), developed by Xonk, originally created by Chocapic. This fork primarily focusses on extended compatibility with *Distant Horizons* and the *Project Haze* mod pack. Based off the `unstable` branch.
